# 🌍 Earth Ranker — Discover Your Global Rarity

**Earth Ranker** is a viral personality rarity app where users answer ~50+ trait-based questions to find out how unique they are among **8.28 billion** people on Earth.

[![Live App](https://img.shields.io/badge/Live-earthranker.himanshurajak.in-blueviolet?style=for-the-badge)](https://earthranker.himanshurajak.in)
[![Tech Stack](https://img.shields.io/badge/Stack-React_|_Vercel_|_AI-cyan?style=for-the-badge)](https://github.com/himanshu-rajak/earth-ranker)

---

## 🚀 Key Features

*   **Personality Rarity Quiz**: A deep dive into your traits to calculate your global rank.
*   **AI Rarity Stories**: Get a personalized, AI-generated narrative about your uniqueness.
*   **Compare with Icons**: See how you stack up against world-famous figures.
*   **Global Leaderboard**: Secure your spot among the rarest individuals on Earth.
*   **PWA Ready**: Install the app on your mobile device for the best experience.

## 🛠️ Tech Stack

*   **Frontend**: React, Tailwind CSS, Vite.
*   **Backend**: Firebase Firestore (Leaderboard), Vercel Edge Functions (AI Proxy).
*   **AI**: Groq (Llama 3.1) for personalized storytelling.
*   **Analytics**: Google Analytics 4.

## 📦 Getting Started

1.  **Clone the repository**:
    ```bash
    git clone https://github.com/himanshu-rajak/earth-ranker.git
    cd earth-ranker
    ```
2.  **Install dependencies**:
    ```bash
    npm install
    ```
3.  **Environment Variables**:
    Create a `.env` file and add the required Firebase and Groq API keys (see `.env.example`).
4.  **Run locally**:
    ```bash
    npm run dev
    ```

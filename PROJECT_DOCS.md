# Earth Ranker — Project Documentation

## 1. Project Overview
**Earth Ranker** is a viral personality rarity app designed to calculate how unique a person is among the global population. Users answer ~50+ trait-based questions to discover their rank and rarity score — e.g., "You are 1 in 8.28 Billion."

*   **Live URL:** [earthranker.himanshurajak.in](https://earthranker.himanshurajak.in)
*   **Mission:** To provide a fun, interactive way for people to discover their uniqueness on Earth using real-world statistical probabilities.

---

## 2. Core Features

1.  **Quiz Flow**: A comprehensive multi-step quiz (~50+ traits) covering biological, sociological, and personal characteristics to determine a rarity score.
2.  **Rarity Scorecard + Certificate**: A polished results dashboard showing the user's rank/tier among 8.28B people, complete with a shareable Canvas-generated certificate.
3.  **AI-Generated Story**: A personalized narrative generated by AI (Groq Llama 3.1) based on the user's specific traits, providing a poetic and unique summary of their rarity.
4.  **Compare with Famous Person**: An interactive feature where users can compare their traits and rarity against a curated list of celebrities and public figures.
5.  **Leaderboard**: A real-time global leaderboard (backed by Firestore) showcasing the "rarest" users discovered so far.
6.  **Challenge a Friend**: A serverless sharing system using base64-encoded URLs that allows users to challenge friends to beat their rarity score.
7.  **Live User Counter**: A dynamic counter on the homepage showing how many people have discovered their rarity today (e.g., "907 people discovered their rarity today").

---

## 3. Tech Stack

*   **Frontend**: React (Vite) with Tailwind CSS for a modern, responsive, and animated UI.
*   **Hosting**: Vercel for high-performance static hosting and Edge Functions.
*   **Backend/Database**: 
    *   **Firebase Firestore**: For real-time leaderboard synchronization.
    *   **Vercel Edge Functions**: Secure proxy for AI API calls.
*   **AI Integration**: Groq API (Llama 3.1) for generating personalized rarity stories.
*   **Analytics**: Google Analytics 4 (GA4) for tracking user engagement and quiz completions.
*   **PWA**: Fully functional Progressive Web App with offline support and install prompts.

## 5. Scoring Logic & Rarity Calculation

The app uses a **Logarithmic Rarity Engine** located in `src/data/rarityData.js`. 
*   It multiplies independent trait probabilities (e.g., Hair Color, Blood Type, Handedness) to find a combined probability.
*   The final result is expressed as **"1 in X Billion"**, capped at the current world population of **8.28 Billion**.
*   A 0–100 score is derived using a logarithmic scale: `score = Math.round((Math.log10(oneIn) / Math.log10(8280000000)) * 100)`.

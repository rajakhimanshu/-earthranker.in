# Earth Ranker — Project Summary

**Earth Ranker** is a high-polish, interactive web application that calculates a user's "Global Rarity Score" by comparing their personality and biological traits against the 8.28 billion global population.

## Core Value Proposition
- **Uniqueness Discovery**: Users answer ~15+ multi-part trait questions to see their statistical rank (e.g., "1 in 8.28 Billion").
- **Viral Engagement**: Highly shareable results, canvas-generated certificates, and base64-encoded friend-challenge links.
- **AI-Driven Personalization**: Personalized rarity narratives generated by Groq Llama 3.1.
- **Global Competition**: Real-time Firestore leaderboard with secure access rules.

## Key Technical Stats
- **Stack**: React 18, Vite 6, Tailwind CSS 3, Firebase Firestore, Groq AI.
- **Scoring**: Logarithmic probability engine normalized against current global population.
- **Performance**: Manual chunking for optimized vendor bundles; PostCSS optimized for Vercel.
- **PWA**: Fully installable with service worker caching.

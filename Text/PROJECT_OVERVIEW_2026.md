# Earth Ranker — Project Overview 2026

## 1. Project Concept
**Earth Ranker** is a high-polish, interactive web application designed to calculate a user's "Global Rarity Score." It uses a probability engine to analyze a combination of biological and sociological traits, comparing the user against the current global population of **8.28 billion**.

## 2. Core Features
- **Personality Rarity Quiz**: A comprehensive animated quiz covering ~50+ traits (Age, Gender, Country, Education, Handedness, Blood Type, Eye/Hair Color, Skills, Birthday, and more).
- **Rarity Scorecard + Certificate**: A polished results dashboard showing the user's rank/tier among 8.28B people, with a shareable Canvas-generated certificate.
- **AI-Generated Story**: A personalized narrative generated by AI (Groq Llama 3.1) based on the user's specific traits, providing a unique summary of their rarity.
- **Compare with Famous Person**: An interactive feature to compare traits and rarity against celebrities and public figures.
- **Global Leaderboard**: A real-time, Firestore-backed leaderboard showcasing the top 100 rarest profiles worldwide.
- **Challenge a Friend**: A serverless sharing system for comparing results side-by-side.
- **Live User Counter**: A dynamic homepage counter showing daily discoveries (e.g., "907 people discovered their rarity today").
- **Multilingual Support**: Full English (EN) and Hindi (HI) localization.
- **PWA Ready**: Installable as a mobile app with offline caching and high-resolution icons.

## 3. Technical Stack
- **Frontend**: React 18, Vite, Tailwind CSS.
- **Backend/API**: Vercel Edge Functions (AI Proxy).
- **Database**: Firebase Firestore (Leaderboard).
- **AI**: Groq API (Llama 3.1).
- **Icons/Graphics**: SVG iconography and high-performance Canvas scorecards.
- **State Management**: React Context (Language/Theme).

## 4. Key Files & Architecture
- `src/pages/Quiz.jsx`: The core interactive engine.
- `src/pages/Result.jsx`: Handles complex math and result visualization.
- `src/pages/Leaderboard.jsx`: Integrated with Firestore for live global rankings.
- `src/data/rarityData.js`: The "source of truth" for statistical fractions used in calculations.
- `src/utils/groqStory.js`: Client for secure AI story generation.
- `api/generate-story.js`: Vercel Edge Function proxying AI requests.

## 5. Development Guidelines
- **Performance**: Prioritize lightweight SVG/CSS and optimized assets.
- **Privacy**: Only public leaderboard names and scores are stored on the server.
- **Consistency**: Maintain the "Deep Purple / Neon" aesthetic across all components.
- **Security**: Never expose API keys on the client; always use the server-side proxy.

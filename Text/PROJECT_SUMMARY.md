# Earth Ranker — Project Summary

**Earth Ranker** is a high-polish, interactive web application that calculates a user's "Global Rarity Score" by comparing their personality and biological traits against the 8.28 billion global population.

## Core Value Proposition
- **Uniqueness Discovery**: Users answer ~50+ trait questions to see their rank (e.g., "1 in 8.28 Billion").
- **Viral Engagement**: Highly shareable results, certificates, and friend-challenge mechanics.
- **AI-Driven Personalization**: Personalized rarity narratives generated by LLMs.
- **Global Competition**: Real-time Firestore leaderboard.

## Key Technical Stats
- **Stack**: React, Vercel, Firebase, Groq AI.
- **Scoring**: Logarithmic probability engine based on real-world census data.
- **Features**: Quiz, AI Story, Leaderboard, Friend Compare, PWA Support.
